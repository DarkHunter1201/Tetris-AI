# Tetris AI 1.0.0 alpha

Tetris AI — приложение для наблюдения за тем, как популяция многослойных нейронных сетей учится играть в собственную реализацию Tetris методом нейроэволюции. Проект предназначен для длительного автономного обучения, а не для игры человеком: управления фигурой с клавиатуры нет.

## Возможности

- Полный игровой движок: 7 стандартных Tetromino, 7-bag, вращения, столкновения, hard drop, очистка линий, score и Game Over.
- Ровно 1500 агентов в каждом поколении.
- Батчевая MLP на PyTorch без создания 1500 отдельных объектов модели.
- Генетический алгоритм с crossover, мутациями и неизменяемой элитой.
- Быстрые headless-симуляции и независимая демонстрация лучшего агента в pygame.
- Автоматическое атомарное сохранение и продолжение обучения.
- CUDA-ускорение с CPU fallback и жёстким лимитом процесса PyTorch 5000 MiB VRAM.
- Реальный мониторинг CPU/RAM через psutil и NVIDIA GPU/VRAM/температуры через NVML.
- Все управляемые приложением кэши, временные файлы, логи и checkpoints находятся внутри проекта.

## Требования

- Windows 11, 64-bit Python 3.10 или новее и подключение к интернету для первой установки.
- NVIDIA GPU необязателен. При совместимой видеокарте и драйвере установщик выбирает официальную CUDA-сборку PyTorch; иначе используется CPU-сборка.
- Для интерфейса нужен обычный графический сеанс Windows.

## Установка и запуск

1. Клонируйте репозиторий.
2. Дважды нажмите `Нажми на меня чтобы подготовиться к запуску.bat`.
3. После успешной установки нажмите `Запустить Tetris AI.bat`.

Установщик создаёт только локальное окружение `.venv`, настраивает project-local кэши, ставит PyTorch и остальные зависимости и проверяет импорты. Повторный запуск установщика безопасен.

Для консольного запуска из подготовленного окружения:

```powershell
.venv\Scripts\python.exe -m tetris_ai
```

Ограниченный headless-запуск:

```powershell
.venv\Scripts\python.exe -m tetris_ai --headless --generations 1
```

Быстрая диагностическая симуляция полного поколения из 1500 агентов с двумя фигурами на агента:

```powershell
.venv\Scripts\python.exe -m tetris_ai --smoke-test
```

## Интерфейс

Слева отображается Tetris-поле лучшего известного агента в наблюдаемом темпе. Справа показаны поколение, fitness, score, линии, прогресс оценки, состояние обучения, устройство, CPU/RAM, GPU load, температура, память процесса PyTorch и общая VRAM. Недоступные NVIDIA-показатели отображаются как `N/A`. Кнопка `EXIT` и крестик окна корректно останавливают worker, сохраняют checkpoint и закрывают pygame.

## Обучение

Сеть получает бинарное поле 10×20, one-hot тип текущей фигуры, высоты колонок, число дыр, неровность и максимальную высоту. Сорок выходов соответствуют сочетаниям четырёх поворотов и десяти колонок. Лучшее допустимое решение выполняется как hard drop.

Каждый агент имеет отдельный плоский набор параметров MLP `220 → 96 → 64 → 40`. Параметры оцениваются батчами. Fitness учитывает score, очищенные линии, продолжительность жизни, высоту, дыры и неровность конструкции. Лучшие 30 агентов копируются без изменений; остальные создаются из 150 лучших родителей crossover и мутацией.

Критические настройки версии 1.0.0 alpha находятся в `src/tetris_ai/config.py`:

- `population_size = 1500`
- `neural_network_vram_limit_mib = 5000`
- версия `1.0.0 alpha`
- параметры мутации, elite count, FPS, polling interval и checkpoint interval

## Данные проекта

Checkpoint: `.runtime/checkpoints/training.pt`.

Логи: `.runtime/logs/tetris-ai.log`.

Все управляемые runtime-данные находятся в `.runtime`: cache, temp, Python bytecode, pip, Torch, CUDA, Inductor, Triton, Numba и Matplotlib. Пути вычисляются относительно текущего расположения проекта и проверяются через resolved absolute path. `.runtime` и `.venv` исключены из Git.

## Структура

```text
src/tetris_ai/
  __main__.py       точка входа
  app.py            жизненный цикл приложения
  config.py         неизменяемая конфигурация 1.0.0 alpha
  paths.py          project-local runtime
  engine.py         Tetris
  network.py        батчевая MLP
  evolution.py      популяция и генетический алгоритм
  trainer.py        headless-обучение
  checkpoint.py     атомарное сохранение
  device.py         CUDA и лимит VRAM
  monitor.py        реальные системные метрики
  state.py          потокобезопасное состояние
  gui.py            pygame-визуализация
tests/               автоматические тесты
```

## Тесты

```powershell
$env:PYTHONPATH="src"
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты проверяют столкновения, вращения, очистку линий, Game Over, reset, checkpoint round trip, популяцию из 1500 агентов, elitism, локальность путей и отсутствие комментариев/docstring в Python-коде.
