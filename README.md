# Tetris AI 1.2.2 rc

Tetris AI — приложение для наблюдения за тем, как популяция многослойных нейронных сетей учится играть в собственную реализацию Tetris методом нейроэволюции. Проект предназначен для длительного автономного обучения, а не для игры человеком: управления фигурой с клавиатуры нет.

## Возможности

- Полный игровой движок: 7 стандартных Tetromino, 7-bag, вращения, столкновения, hard drop, очистка линий, score и Game Over.
- По умолчанию 1500 агентов в каждом поколении, количество свободно настраивается от 1.
- Батчевая MLP и пакетная Tetris-симуляция на PyTorch без создания 1500 отдельных объектов модели.
- Генетический алгоритм с crossover, мутациями и неизменяемой элитой.
- Быстрые headless-симуляции и независимая демонстрация лучшего агента в pygame.
- Автоматическое атомарное сохранение и продолжение обучения.
- Автоматический выбор наиболее производительной CUDA GPU с CPU fallback.
- Постоянное размещение популяции, игровой симуляции и эволюции на GPU.
- Автоматический или ручной лимит VRAM из интерфейса без изменения кода.
- Настраиваемое количество агентов в поколении без изменения исходного кода.
- Все 34 параметра модели, эволюции, fitness, rule-aware стратегии, CUDA, языка и визуализации изменяются в приложении.
- Контекстная справка по наведению на значок `i` у каждого параметра обучения и аппаратного показателя.
- Полная русская и английская локализация с сохранением выбранного языка.
- Автоматический подбор модели по CPU, GPU, VRAM, объёму, типу и частоте RAM с безопасным ограничением по самому слабому ресурсу.
- Возврат всех параметров модели к значениям по умолчанию одной кнопкой.
- Реальный мониторинг CPU/RAM через psutil и NVIDIA GPU/VRAM/температуры через NVML.
- Все управляемые приложением кэши, временные файлы, логи и checkpoints находятся внутри проекта.

## Требования

- Windows 11, 64-bit Python 3.10 или новее и подключение к интернету для первой установки.
- NVIDIA GPU необязателен. При совместимой видеокарте и драйвере установщик выбирает официальную CUDA-сборку PyTorch; иначе используется CPU-сборка.
- Для интерфейса нужен обычный графический сеанс Windows.

## Установка и запуск

1. Клонируйте репозиторий.
2. Дважды нажмите `Нажми на меня чтобы подготовиться к запуску.bat`.
3. После успешной установки нажмите `Запустить Tetris AI.bat`.

Установщик создаёт только локальное окружение `.venv`, настраивает project-local кэши, ставит PyTorch и остальные зависимости и проверяет импорты. Повторный запуск установщика безопасен.

Для консольного запуска из подготовленного окружения:

```powershell
.venv\Scripts\python.exe -m tetris_ai
```

Ограниченный headless-запуск:

```powershell
.venv\Scripts\python.exe -m tetris_ai --headless --generations 1
```

Быстрая диагностическая симуляция полного поколения из 1500 агентов с двумя фигурами на агента:

```powershell
.venv\Scripts\python.exe -m tetris_ai --smoke-test
```

## Интерфейс

Слева отображается Tetris-поле лучшего известного агента в наблюдаемом темпе. Справа показаны поколение, fitness, score, линии, доля ходов с вращением, прогресс оценки, состояние обучения, устройство, CPU/RAM, GPU load, температура, память процесса PyTorch и общая VRAM. Недоступные NVIDIA-показатели отображаются как `Н/Д` или `N/A` в зависимости от языка. Датчики загрузки, температуры и памяти опрашиваются не чаще одного раза в 1,5 секунды.

Кнопка `PAUSE` останавливает обучение и визуализацию в текущем состоянии, а `START` продолжает работу. `RESET` после повторного подтверждения автоматически ставит обучение на паузу, удаляет основной и временный checkpoint, освобождает прежнюю популяцию и лучший геном, сбрасывает статистику и генератор эволюции, создаёт новую случайную популяцию с новым seed и заменяет геном визуализации. После сброса обучение не начнётся до нажатия `START`.

В секции `VRAM LIMIT` доступен автоматический режим `AUTO`, ползунок и поле ручного ввода в MiB. Настройка применяется во время работы и сохраняется в `.runtime/data/settings.json`. При следующем запуске она загружается автоматически. Для CPU-режима элементы управления VRAM отключены.

В поле `AGENTS PER GENERATION` можно ввести любое целое число от 1 без программного верхнего ограничения. Фактический предел определяется доступной RAM/VRAM. Нажатие `APPLY` сохраняет значение и выполняет полный reset, поскольку популяции разного размера нельзя безопасно смешивать. Число элитных агентов и родительский пул масштабируются пропорционально размеру популяции.

Кнопка `НАСТРОЙКИ` / `SETTINGS` открывает прокручиваемый экран всех 34 доступных параметров. Редактируются язык, размеры поля и скрытых слоёв, популяция, элита и родители, вероятность и сила мутации, crossover, влияние сети, seed, все rule-aware и fitness-коэффициенты, ограничения оценки и checkpoint, CUDA/VRAM, FPS и частота мониторинга. Значок `i` рядом с каждым названием показывает назначение параметра. `ПРИМЕНИТЬ И СБРОСИТЬ` / `APPLY & RESET` требует повторного подтверждения, атомарно сохраняет настройки, полностью удаляет несовместимый checkpoint и перезапускает worker с поколения 0. Размер выходного слоя вычисляется безопасно как `ширина поля × 4`.

Кнопка `АВТО` / `AUTO` считывает модель и вычислительные блоки CUDA GPU, объём VRAM, модель и количество ядер CPU, общий объём RAM, SMBIOS-тип DDR/LPDDR и настроенную частоту памяти. На их основе она предлагает размер популяции, скрытые слои, вычислительный пакет, длину партии и безопасный автоматический бюджет VRAM. Значения сначала показываются как черновик и ничего не меняют до подтверждения.

Кнопка `ПО УМОЛЧАНИЮ` / `DEFAULTS` возвращает черновик к исходным значениям модели. Текущий язык при этом сохраняется. Смена только языка применяется без удаления checkpoint; изменение характеристик модели по-прежнему требует полного reset.

Значки `i` также находятся рядом со всеми показателями Training и Hardware, включая температуру GPU, память, загрузку, устройство и состояние worker.

Окно можно свободно растягивать мышью. Поле, панель, кнопки и элементы VRAM автоматически перестраиваются под доступный размер. Кнопка `EXIT` и крестик окна корректно останавливают worker, сохраняют checkpoint и закрывают pygame.

## Обучение

Цвета обозначают типы фигур только для визуального различия. По стандартным правилам Tetris совпадение цветов не требуется: очищается полностью заполненная горизонтальная линия из фигур любых цветов.

Сеть получает бинарное поле 10×20, one-hot тип текущей фигуры, высоты колонок, число дыр, неровность и максимальную высоту. Сорок выходов соответствуют сочетаниям четырёх поворотов и десяти колонок. Перед каждым hard drop движок моделирует все допустимые размещения и оценивает очистку линий, суммарную и максимальную высоту, дыры и неровность. Ограниченный через `tanh` вклад сети дополняет эту обязательную rule-aware оценку и не может заставить агента игнорировать базовые правила Tetris.

По умолчанию каждый агент имеет отдельный плоский набор параметров MLP `220 → 96 → 64 → 40`; размеры поля и скрытых слоёв изменяются в интерфейсе, а входной и выходной слои пересчитываются автоматически. Все агенты одного поколения получают одинаковую детерминированную 7-bag последовательность фигур, поэтому их fitness сравнивается в равных условиях. В предыдущей реализации каждый агент получал собственную случайную последовательность, что добавляло сильный шум и могло создавать впечатление, что сеть не учится вращать фигуры.

При наличии CUDA популяция, состояние 1500 игровых полей, нейросетевой inference и генетическая эволюция находятся на GPU. Размер вычислительного батча рассчитывается автоматически по выбранному лимиту VRAM и уменьшается при нехватке памяти. CPU остаётся для интерфейса, мониторинга, checkpoint и служебного управления. В CPU-only системе тот же пакетный движок работает без CUDA.

Fitness значительно сильнее вознаграждает очищенные линии и штрафует дыры, высоту, неровность и Game Over. Это устраняет стратегию случайного наваливания фигур ради короткого выживания. При стандартной популяции лучшие 30 агентов копируются без изменений; остальные создаются из 150 лучших родителей crossover и мутацией. Для пользовательской популяции эти размеры масштабируются автоматически.

Значения по умолчанию версии 1.2.2 rc находятся в `src/tetris_ai/config.py`, а изменённые пользователем значения — в `.runtime/data/settings.json`:

- `population_size = 1500`
- `neural_network_vram_limit_mib = 0`, где `0` включает автоматический режим
- автоматический лимит использует до 85% VRAM и оставляет системный резерв
- опрос аппаратных датчиков выполняется раз в 1,5 секунды
- язык по умолчанию — русский, доступен английский
- версия `1.2.2 rc`
- параметры мутации, elite count, FPS, polling interval и checkpoint interval

## Данные проекта

Checkpoint: `.runtime/checkpoints/training.pt`.

Пользовательские настройки: `.runtime/data/settings.json`.

Логи: `.runtime/logs/tetris-ai.log`.

Все управляемые runtime-данные находятся в `.runtime`: cache, temp, Python bytecode, pip, Torch, CUDA, Inductor, Triton, Numba и Matplotlib. Пути вычисляются относительно текущего расположения проекта и проверяются через resolved absolute path. `.runtime` и `.venv` исключены из Git.

## Структура

```text
src/tetris_ai/
  __main__.py       точка входа
  app.py            жизненный цикл приложения
  config.py         значения конфигурации 1.2.2 rc по умолчанию
  paths.py          project-local runtime
  engine.py         Tetris
  batch_engine.py   пакетная CPU/CUDA-симуляция Tetris
  network.py        батчевая MLP
  evolution.py      популяция и генетический алгоритм
  trainer.py        headless-обучение
  checkpoint.py     атомарное сохранение
  device.py         CUDA и лимит VRAM
  settings.py       сохраняемые настройки интерфейса
  settings_panel.py прокручиваемый редактор всех параметров и справка
  autotune.py       профиль оборудования и автоматический подбор модели
  translations.py  полная русская и английская локализация
  monitor.py        реальные системные метрики
  state.py          потокобезопасное состояние
  gui.py            pygame-визуализация
tests/               автоматические тесты
```

## Тесты

```powershell
$env:PYTHONPATH="src"
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты проверяют совпадение пакетного и обычного игровых движков, rule-aware очистку линий, выбор повёрнутых фигур, 7-bag, Game Over, pause/start, полное уничтожение checkpoint и старого генома при reset, безопасную смену языка без reset, автоматические профили слабого CPU и мощного CUDA-компьютера, полноту русского перевода, интервал датчиков 1,5 секунды, схему и валидацию всех параметров, обратную совместимость настроек VRAM, checkpoint round trip, elitism, локальность путей и отсутствие комментариев/docstring в Python-коде.
